# `javap` (Java Class File Disassembler) ⭐⭐⭐

Don't think of `javap` as a JVM concept.

Think of it as **a debugging/inspection tool**.

It answers the question:

> **"What did the Java compiler actually generate?"**

---

# What is `javap`?

`javap` is a JDK command-line tool that **disassembles** a compiled `.class` file into a human-readable form.

```text
.java
   │
javac
   │
.class
   │
javap
   │
Human-readable bytecode
```

It **does not** decompile back to Java source code.

It shows the JVM instructions stored in the class file.

---

# Why is it useful?

Suppose you write:

```java
int c = a + b;
```

You know the compiler generates bytecode.

How do you verify it?

Using:

```bash
javap -c Main
```

---

# Common Commands

### Show class information

```bash
javap Main
```

Output:

```text
public class Main {
  public Main();
  public static void main(java.lang.String[]);
}
```

---

### Show bytecode (Most Used)

```bash
javap -c Main
```

Example output:

```text
0: bipush        10
2: istore_1
3: bipush        20
5: istore_2
6: iload_1
7: iload_2
8: iadd
9: istore_3
10: return
```

Now you can directly see the bytecode generated by `javac`.

---

### Verbose Output (Occasionally Asked)

```bash
javap -v Main
```

Shows additional details such as:

* Class version
* Constant Pool
* Stack size
* Local variable table
* Line number table
* Bytecode
* Method descriptors

This is especially useful when debugging or learning JVM internals.

---

# Example

Source:

```java
public class Main {

    public static void main(String[] args) {

        int a = 10;
        int b = 20;

        System.out.println(a + b);
    }
}
```

Run:

```bash
javac Main.java

javap -c Main
```

You'll see instructions similar to:

```text
bipush 10
istore_1

bipush 20
istore_2

iload_1
iload_2
iadd

getstatic java/lang/System.out

invokevirtual java/io/PrintStream.println

return
```

Notice how **one Java statement becomes multiple JVM instructions**.

---

# When do we use `javap`?

* Learning JVM internals.
* Understanding compiler output.
* Verifying bytecode.
* Investigating performance or compiler behaviour.
* Explaining interview questions.

---

# Interview Questions

### Q1. What is `javap`?

**Answer:**

`javap` is a JDK tool that disassembles a compiled `.class` file into a human-readable representation of the bytecode and class metadata.

---

### Q2. Does `javap` decompile Java source code?

No.

It disassembles bytecode. It shows JVM instructions, not reconstructed Java source.

---

### Q3. Which `javap` options should I remember?

For interviews, these are enough:

```bash
javap Main
javap -c Main
javap -v Main
```

# Do interviewers ask `javap`?

For a **7+ years Backend Java Developer**:

* **What is `javap`?** → Occasionally
* **Have you used `javap`?** → Sometimes
* **Explain every `javap` option.** → Rarely
* **Interpret a small `javap -c` output.** → Fair game

So don't memorise every flag. Just know:

* What it is.
* Why it's useful.
* The three common commands above.
* How to relate the output to Java source code.
