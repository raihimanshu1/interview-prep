```text
Simple concept question:
Definition -> simple terms -> why it matters -> example -> safe vs unsafe -> production mindset -> quick mental model -> interview answer

Design / LLD / HLD question:
Problem statement -> requirements -> flow -> approaches -> data structures/classes -> algorithm -> concurrency -> distributed state -> production architecture -> follow-ups -> senior-level answer
```

Reject drafts that are too abstract, too textbook-like, missing examples, missing tradeoffs, missing Java/Spring production details, duplicated, or not speakable in an interview.
