## Extra Coding Prompts To Practice Out Loud

1. Given transaction logs, find accounts with more than N failed logins in a rolling 10-minute window.
2. Given API latency records, return the top K slowest endpoints by p95 latency.
3. Given duplicate payment events, deduplicate by idempotency key while preserving first accepted timestamp.
4. Given customer-service case events, compute average time spent in each case state.
5. Given two sorted audit streams, merge them and detect missing sequence numbers.
6. Given employee salary rows, find the minimum salary per department using SQL and then Java maps.
7. Given a string with wildcard characters, decide whether it matches a transaction reference pattern.
8. Given daily account balances, find the longest period below threshold.
9. Given dependency pairs among batch jobs, return a valid execution order or detect a cycle.
10. Given fraud-rule scores, maintain a moving top K risky accounts.
