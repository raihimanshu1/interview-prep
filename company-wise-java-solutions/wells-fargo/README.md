## What To Prioritize For Senior Java

1. Java deep dive: OOP, collections, streams, exception handling, immutability, concurrency, JVM memory, GC, and performance.
2. Spring Boot backend: REST APIs, validation, transactions, security, integration tests, resilience, and microservices boundaries.
3. Banking-grade system design: consistency, auditability, idempotency, fraud signals, ledger correctness, high availability, and disaster recovery.
4. SQL and data: joins, indexes, query plans, isolation levels, normalization, sharding, partitioning, and reconciliation queries.
5. DSA: mostly Easy/Medium arrays, strings, stack, linked list, matrix, heap, design, graph BFS/DFS, and a few hard cache/backtracking problems.
6. Behavioral: leadership, code quality, ownership under ambiguity, production incidents, conflict, mentoring, and regulated-environment judgment.
