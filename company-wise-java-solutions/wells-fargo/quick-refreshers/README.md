## Answer Shape

Each topic follows the same interview-friendly shape:

```text
What is it?
In simple terms
Why it matters
Example
Safe vs unsafe / common mistake
Production mindset
Follow-up questions
Interview answer
```

For design topics, also include:

```text
requirements
flow
trade-offs
failure handling
scaling
observability
```
