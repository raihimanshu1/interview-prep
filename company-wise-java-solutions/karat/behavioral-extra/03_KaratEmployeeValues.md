# Which employee values matter to you?

## Problem In Simple Words

Values alignment prompt. They want evidence of how you work.

## Input / Context Meaning

This prompt is checking how you behave in real engineering situations. For a 7+ years profile, answer with a specific story or a precise operating principle, then show judgment, ownership, and measurable learning. For this question, keep the focus on: Which employee values matter to you?

## School-Level Intuition

Pick values you can prove with behavior.

## Basic Answer

The values I care about are clarity, ownership, and fairness. Clarity means making tradeoffs visible. Ownership means caring about production outcomes. Fairness means using evidence rather than hierarchy.

## Strong 7+ Years Answer

The values I care about most are clarity, ownership, and fairness. Clarity means I make requirements, tradeoffs, and risks visible. Ownership means I do not stop at writing code; I care whether the feature works in production. Fairness means I listen to different viewpoints and use evidence rather than hierarchy to make decisions. These values show up in how I design systems, review code, and communicate during ambiguity.

## Why This Answer Works

This works because it gives the interviewer concrete evidence instead of adjectives. It shows what you personally did, why you chose that action, and how the result changed the project, team, or decision quality.

## Anti-Pattern Answer

Listing generic values with no examples.

## Advanced Version / Add-On

Advanced answer: connect each value to behavior under pressure, like incidents, design disagreements, and code reviews.

## STAR Breakdown

Situation: Asked values.
Task: Show values with evidence.
Action: Name values and behaviors.
Result: Interviewer understands how you operate.

## Dry Run / Walkthrough

Value -> behavior -> example -> impact.

## Follow-Up Questions To Prepare

- If asked “hardest value,” say fairness under deadline pressure.
- If asked “example,” use code review or incident.
- If asked “conflict,” discuss tradeoff.

## Final Interview Checklist

- Start with the situation in one sentence.
- Make your personal action clear.
- Add a senior signal: tradeoff, risk, metric, mentoring, or production impact.
- Keep the story under two minutes, then let the interviewer ask deeper probes.
- Avoid blame; show ownership and learning.
